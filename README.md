# 🎬 Netflix Movies and TV Shows Data Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing the Netflix dataset using SQL to extract meaningful insights about movies and TV shows available on the platform.

The project involves solving real-world business questions using SQL queries to understand content distribution, ratings, release trends, popular directors, actors, genres, and country-wise content availability.

## 📊 Dataset Description

The dataset `netflix_titles` contains information about Netflix movies and TV shows.

### Dataset Columns

| Column Name | Description |
|---|---|
| show_id | Unique ID of each title |
| type | Movie or TV Show |
| title | Name of the movie or TV show |
| director | Director's name |
| cast | Actors and cast members |
| country | Country of production |
| date_added | Date added to Netflix |
| release_year | Original release year |
| rating | Content rating |
| duration | Movie duration or number of seasons |
| listed_in | Genre or category |
| description | Short description of the content |

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Identify the most common content ratings.
- Explore movies released in specific years.
- Find the top 5 countries producing Netflix content.
- Identify the longest movie.
- Analyze recently added Netflix content.
- Find movies and TV shows by a specific director.
- Identify TV shows with more than 5 seasons.
- Analyze content distribution by genre.
- Examine year-wise Netflix content releases in India.
- Identify documentary movies.
- Find content with missing director information.
- Analyze movies featuring Salman Khan.
- Identify the top 10 actors appearing in Indian movies.
